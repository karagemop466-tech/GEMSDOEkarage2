# Project starting point

Read [README.md](README.md), the user's operating charter there, and the latest
[evidence/run-card.json](evidence/run-card.json) before changing this project.
Read the [scientific review](research/findings-2026-10-27.md) and
[preregistered hypotheses](research/hypotheses-2026-10-27.md) before proposing
or running experiments. Do not mistake a historical record for current approval.

* Maximize P(Win); own the outcome. Be explicit about missing evidence and negative results.
* The parallel protocol requires an explicitly assigned single method lane, no
  more than three experiments or two hours, feature-only leakage canaries,
  buffered whole-segment visible-only holdouts, and pre-placement and final-dot
  uniqueness checks against a complete registry. A duplicate means STOP.
* Never claim an estimated leaderboard score without validated calibration or
  call an owner report an organizer receipt. Label every scientific score with
  its evidence class, evaluator version, withheld count and interval.
* Never promote a TIFF from a format check alone, rename/copy an old submission,
  select a weekly slot during a research run, or fabricate a download. Use the
  shared template tools rather than privately forking them; report upstream
  issues honestly. The static site currently supports the negative decision only.
* Do not commit large datasets, caches, credentials, unapproved TIFFs or generated
  binary artifacts. Read and follow the current organizer rules and terms.

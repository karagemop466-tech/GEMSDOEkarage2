Limitations and what would improve this

  • The independent SGMC instrument is not the hidden expert truth; it is a different public mapping of the same area, and the two disagree for some historical submissions (the 18-point fit has R² 0.516, leave-one-out RMSE 0.0667).
  • The emission policy (radius, dot budget, catalogue apron) was chosen on the same blocked instrument, so the reported HOLDOUT-DTI is selection-biased upward; the spread across 36 policy combinations is recorded in the receipt.
  • The blocked holdout uses four spatial quadrants; more folds and a per-fold CI would tighten the interval. A GPU would allow per-fold retraining of the full feature stack and a proper bootstrap CI.
  • The registry snapshot covers nine public repositories only; a duplicate outside it cannot be excluded.
  • The next lane should attack precision rather than coverage: the metric charges 0.2 for a false positive but 0.8 for a missed truth cell, so fewer, better-placed dots win - and the measured marginal hit rate of this detector still exceeds the break-even rate up to about 100,000 dots.

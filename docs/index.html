💡 Why GEMSDOE32's 0.2778 leads — and why copying it cannot win

  • The 0.2778 champion is the GEMSDOE31 solo-dot set with 2,545 catalogue-adjacent dots removed (37,654 dots). GEMSDOE25 and GEMSDOE30 have the same dot geography; GEMSDOE36 contains every champion dot plus 1,200 extras.

  • All nine share one dot geography and fail the literal uniqueness gate (>70% within 3 px of each other / of the spacing-5 calibration lattice, which covers 99.8713% of the footprint). A different file hash is not a new geological method.

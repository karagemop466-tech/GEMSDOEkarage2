Score estimate: how the number is built, and how much to trust it

There is no organizer receipt for any local file, and no label set for the hidden truth, so a score cannot be measured here. What can be done is to project one from a stated model and publish the assumptions. The projection uses the identity fitted on the verified subset contrasts:

DTI = T / (0.2·T + 0.2·(n − M) + 0.8·K̂), with K̂ = 14,200 (identified from bytes, range 13,368–15,200).

T (kernel credit) and M (per-dot credit total) are measured on the 4-quadrant catalogue holdout at each emission budget. They are then transferred to the hidden truth through a coefficient λ: the fraction of holdout-measured credit that survives onto the off-catalogue test set. λ is unknown and unmeasurable locally — the two anchor files in the family imply anything from 0.66 to 13.9 — so it is swept rather than guessed.

Why 0.2778 won — and what that tells us

  1. It is a pruning operation, not a new detector. Byte-level set comparison proves GEMSDOE32 ⊂ GEMSDOE31 ⊂ GEMSDOE25. GEMSDOE25 emits 44,090 dots; GEMSDOE31 is that set with the 3,891 dots within 100 m of a mapped fault deleted; GEMSDOE32 deletes a further 2,545 dots out to 200 m. The 6,436 deleted dots are a strict subset — no new geology was added.
  2. The gain is pure metric arithmetic. With the official kernel, DTI = T / (0.2·T + 0.2·(n − M) + 0.8·K). Deleting a dot that earns no kernel credit leaves T unchanged and removes 0.2 from the denominator, so DTI must rise. Fitting that identity to the three verified contrasts gives a hidden-truth size K̂ ≈ 14,200 pixels (13,368–15,200 across the three contrasts) and a kernel credit T ≈ 5,250 shared by the whole dot pool. The three independent contrasts agree to ±7%.
  3. The deleted dots were worth nothing because the organiser masks mapped faults. The scored domain excludes pixels corresponding to the existing USGS/INGENIOUS faults, so a dot inside that zone cannot earn credit but still costs 0.2. Fitting the reported scores forces the credit of the deleted dots to ≈0, and their per-dot credit is at most 0.055 against a pool average of 0.139.
  4. Catalogue rediscovery is anti-correlated with the leaderboard. Across all nine files, a 4-quadrant hide-and-recover score against the public catalogue has Spearman -1.00 against the reported leaderboard — perfectly reversed, at every catalogue-exclusion width we swept (0–8 px). Any pipeline that selects on "how well does this rediscover known faults" will systematically pick the worst file.
  5. So the score is dominated by emission mass, not geology. Within this family every file collects essentially the same kernel credit T ≈ 5,200; the spread from 0.2449 to 0.2778 is almost entirely the denominator 0.2·n. The whole family sits inside one dot pool with one shared ancestor.

How this file was produced

  1. Features — 34, all from the 19 official GeoDAWN bands. The 19 bands as delivered, plus gradient magnitudes at 100 m and 400 m scales for the reduced-to-pole magnetics, isostatic gravity, detrended elevation and total magnetic intensity; gradients of depth-to-basement, surface conductivity, the geodetic second invariant and the magnetic anomaly; Laplacian ridge filters on elevation and magnetics; and 5×5 local standard deviations. Nothing catalogue-derived enters the model, so the spatial holdout cannot leak withheld segments through a feature.
  2. Model — gradient-boosted trees, spatially blocked. Four quadrant folds; for each fold the model is trained only outside the held-out quadrant and scored inside it. Holdout AUC by fold: fold c 0.627, fold c 0.710, fold c 0.630, fold c 0.691. Positives are the 60,988 public-catalogue pixels; negatives are sampled 8:1.
  3. Leakage canary — passed. Every one of the 34 features was scored alone against the labels. Maximum single-feature AUC is 0.5848, far below the 0.90 escalation threshold; features flagged: {}.
  4. Emission — top-100,000 pixels by predicted prospectivity, restricted to pixels more than 5 px (500 m) from any mapped fault. All emitted values are exactly 1.0; binary emission is optimal under this metric because the marginal-acceptance inequality k > α·DTI is rank-only.
  5. Exterior convention — finite zeros outside the footprint. Every one of the 12,279,160 cells in the array is finite and inside [0, 1], so the portal's "Predicted values must be in range [0, 1]" check passes whether it is applied to the whole array or only to the footprint. A NaN exterior fails under the whole-array implementation, which is the most likely cause of the rejection reported earlier. The two highest-scoring files in the focus family both use zeros outside. Flagged as IR-EXTERIOR-01: the repository's own scripts/submission_writer.py additionally demands NaN outside and would reject this file.

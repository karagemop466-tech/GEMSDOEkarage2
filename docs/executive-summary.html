WHEN A FUTURE FILE IS APPROVED

Submission checklist

01

Confirm the decision first

Use a new file only when its run card shows an assigned lane, passing feature canaries, a same-protocol holdout win, complete surface and dot novelty, saved-byte validation, and separate selector approval. Current verdict: negative.

02

Download the exact approved file

The project must show its unique filename, SHA-256 and a note of at most 140 characters. Verify the downloaded bytes against the run card. Never rename or resubmit a historical raster as a new model.

03

Check the competition form

Sign in and open DrivenData GEMS → Submit → Make new submission. Confirm the account’s current remaining weekly quota and rules. Choose the approved single-band GeoTIFF, or a ZIP containing exactly one GeoTIFF, and paste its short note.

04

Keep the receipt

After an authorized upload, retain the organizer receipt, exact file SHA and resulting score. A local HOLDOUT-DTI is a screening result—not an organizer score or a reliable leaderboard forecast.

FORMAT REQUIREMENTS

What the organizer describes

  • Single-band float32 GeoTIFF
  • Predictions in [0, 1]
  • EPSG:32611, 100 m grid
  • Match the official template's shape and geotransform
  • Outside-bounds null/NaN per the published description

Why GEMSDOE32 (0.2778) leads this group — and whether it can be beaten

GEMSDOE32's reported 0.2778 is the highest of the nine user-reported claims, but it is USER-REPORTED / UNVERIFIED — there is no file-linked organizer submission receipt. The pinned GEMSDOE32 mask is the GEMSDOE31 mask with 2,545 known-fault-adjacent pixels removed (no dots added); GEMSDOE25 and GEMSDOE30 are identical inside the mirror footprint; GEMSDOE36 contains the GEMSDOE32 mask plus 1,200 pixels. These are reproduced geometry facts on an unauthenticated mirror, not evidence of where hidden faults occur.

Under the official distance-weighted Tversky metric (DTI, α=0.2, β=0.8, triangular kernel R=300 m), each prediction dot earns credit only near truth and is penalized for unsupported positive mass. A dot adds value only if its hit probability exceeds α × DTI (≈ 0.056 at DTI 0.2778). Removing low-yield dots can raise the balance, but it can also lose true-positive credit. Because hidden truth and a file-linked receipt are unavailable, the causal explanation for 0.2778 is not established, and nothing here proves a new file will exceed it.

Can it be beaten? Yes — in principle. A sparse, high-confidence submission that places fewer, well-targeted dots (like the new H-A file above, 2,524 positives vs 37,654) reduces false-positive mass under α=0.2. But beating 0.2778 on the hidden private label set requires organizer data to validate. The official public leaderboard showed 0.4544 (xiaofanhu, rank 1) on 2026-10-28 — a public snapshot, not a receipt, and it can change.

Blind/covered strands leave no surface trace but still intersect at depth, producing alteration halos and curvature signatures. SGMC includes Quaternary/pre-Quaternary faults the USGS catalogue may omit. Targeting off-catalogue strands within <2 km basement depth addresses blind structures directly. Repo lanes mask known catalogue faults pixel-exactly. H-B uses off-catalogue faults as positive priors — complementary, not duplicate. No focus site uses SGMC off-catalogue distance.

No repo lane or focus submission uses seismicity or strain rate. Earthquake catalogs are independent of fault truth labels, so the leakage canary should pass easily.
4 · low (H-D) GeoDAWN radiometrics K, eU, eTh ternary alteration index (e.g., (eU+eTh)/K). Signature: hydrothermal alteration mobilizes U/Th and leaches K along fluid pathways. Alteration halos extend beyond surface fault traces, revealing blind strands under cover. The catalogue maps traces, not halos. Buried/covered faults deform the surface over wide areas without a mapped trace; multi-scale anisotropy separates faults from isotropic terrain noise. Existing work uses single-scale scarp openness/ridge. H-E uses multi-scale multi-directional density with anisotropy — a different transform family. DEM available from USGS 3DEP (free).

How to make a submission into the contest (when cleared)

  1. Wait for the decision to change. One assigned lane must pass feature leakage canaries (≤ 0.90 AUC), buffered whole-segment hide-and-recover with fold-local catalogue features, and a matched current-best comparison with a paired 95% confidence interval. Surface and final dots must pass uniqueness against the complete current registry (Spearman ≤ 0.90, ≤ 70% of dots within 3 px).
  2. Validate the exact saved bytes automatically. Use the authenticated organizer sample for CRS (EPSG:32611), shape (3730 × 3292), transform (100 m), and footprint. Check one float32 band, no NaN/Inf inside, all values in [0,1]. No manual image inspector is used by these gates.
  3. Run the separate selector. Only an eligible candidate and the available weekly allowance authorize a slot. The rules describe a limit of three feedback submissions per week; confirm the current allowance in your account.
  4. Download the approved TIFF. When the project provides an approved file, download that exact hash-validated file. Use its unique name and a note of at most 140 characters; do not copy an old raster.
  5. Submit through DrivenData. Open the competition, choose "Submit" then "Make new submission," select the TIFF (or a ZIP containing a single TIFF), paste the note, and submit. Save the organizer's receipt linked to the exact file hash.
  6. Finalize once. Select one submission for both prize rounds before the deadline. Retain reproducible code and documentation. Official rules.

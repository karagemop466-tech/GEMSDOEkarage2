2. Why the GEMSDOE32 file scored 0.2778 (and why none of the nine should be re-submitted)

Metric. The competition uses a distance-weighted Tversky index (α = 0.2, β = 0.8, 300 m triangular kernel), with mapped-fault pixels excluded, as described on the official problem page. The scorer accumulates distinct kernel-weighted sums over truth pixels and prediction pixels; it cannot generally be reduced to a single shared T/F/G count identity. Therefore the earlier algebraic reconstruction of hidden truth size and B2 credit is only an unverified heuristic, not exact metric arithmetic and not an organizer-confirmed score explanation. See the metric correction.

Historical calibration sensitivity analysis (not validated score estimation). An earlier internal note tried to infer hidden-set quantities from the user-reported lattice score and a simplified DTI identity. That identity is not valid for the official distance-weighted metric, so the implied hidden-truth estimate, interval and derived hit counts must not be interpreted as estimates of organizer labels. The corresponding calibration JSON is retained as an auditable historical calculation, not as a leaderboard predictor. A trustworthy leaderboard estimate is unavailable without a file-bound organizer receipt and validated transfer data.

Nested family. Exact set relations on the pinned owner-mirror bytes: GEMSDOE25 and GEMSDOE30 have the same decoded dots; GEMSDOE31 removes mapped-catalogue-near dots; GEMSDOE32 removes an additional catalogue-distance band; GEMSDOE36 adds dots back. These byte-level relationships are reproducible, but the user-reported score differences do not identify a causal mechanism because the hidden labels are unavailable and the simplified metric reconstruction was invalid. We can say that geometry/emission changed across this family; we cannot prove from these records why 0.2778 was reported or calculate the private-set hit/false-positive counts.

Implication. Sparse emission can reduce redundant false-positive mass under distance-tolerant metrics, but no optimal dot budget or score gain is established by these observations. The high-scoring focus files are not suitable for resubmission because their predicted dots substantially overlap one another, and the current HK3 artifact also fails the stricter full-registry gate.

3. What the historical HK3 research artifact tested

  • Lane (single method): HK3 (self-declared; no coordinator paragraph supplied): catalogue-free edge-centrality surface + calibrated off-catalogue dot emission.
  • Hypothesis: Thin linear slope maxima of detrended elevation (gradient-ridge centrality, structure-tensor coherence) and amplitude-normalised potential-field edges (gravity/magnetic tilt-angle zero-crossing distance) mark fault scarps that 1:100k mapping missed; a per-fold HGB on 34 bands learns them from visible faults only.
  • Mechanism: Scarps are linear maxima of slope; range-front and intrabasin faults juxtapose density/magnetisation contrasts whose tilt-angle zero crossing sits over the edge independent of amplitude; 3 px catalogue apron and 3 px separation follow the calibrated metric geometry (E1).
  • Named non-fault mimic: lithologic/intrusive contacts (same potential-field step), pluvial shorelines and terrace risers (linear slope maxima), survey flight-line striping.
  • Protocol: shared evaluator gems57-pooled-hide-v2; K2 label-blind quadrant folds, 80 px buffer, visible faults masked pixel-exactly, model refit per fold; catalogue features from visible faults only; α 0.2 / β 0.8 / 300 m triangular kernel; paired spatial-block bootstrap (158 blocks, 2000 draws).
  • Leakage canary: max single-feature AUC 0.596 (limit 0.90) — pass for all eight new bands.
  • Primary comparison — HOLDOUT-DTI (evaluator gems57-pooled-hide-v2; 58,258 withheld positives; 95% CIs): at the matched 1.10% budget, candidate 0.1845 [0.1677, 0.2015], re-fitted incumbent 0.1575 [0.1417, 0.1737]; paired difference +0.0270 [0.0206, 0.0337]. This is a catalogue hide-and-recover comparison, not an organizer score.
  • Artifact: 45,108 positive pixels on saved raster; this is a research-only run output. Its registry gate failed, so this holdout gain does not authorize release.

Leaderboard estimate: unavailable. The previously displayed calibrated score curve depended on a simplified DTI identity that is inconsistent with the official distance-weighted metric.

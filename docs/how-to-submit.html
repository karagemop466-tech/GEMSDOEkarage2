When a future file is approved

  1. Check the run card and the separate selector decision. Confirm the assigned lane, holdout improvement with a paired confidence interval against the matching incumbent, per-feature leakage canaries, and both surface and final-dot registry checks.
  2. Download the approved GeoTIFF from its release, verify its SHA-256 against its run card, and check its validator receipt. Verify against the organizer’s actual template, including band count, CRS, shape, transform, values and exterior/nodata policy.
  3. On DrivenData, sign in, check the current rules, deadline and remaining weekly quota, and open the submission form. Select the approved single-band TIFF, or a ZIP containing that one TIFF.
  4. Enter the file’s short run-card note (at most 140 characters under this project’s protocol), submit only if the separate selector approves a slot, and keep the organizer’s receipt with the file hash. A unique filename alone does not prove a unique prediction.

The form description supplied in the request mentions a file and optional note, not a separate name field; use a distinct filename.

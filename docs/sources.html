Irregularities that matter

Original checkout contained only a one-line README. No previous pipeline, cached stack, holdout best or session notes existed. Data placement is now resolved using mirrors, not authenticated organizer downloads.

Not a live leaderboard

The prompt cites conflicting current highs. No organizer receipt or authenticated current ranking was accessible. Historical values are segregated as unverified user claims.

Not global uniqueness

The registry is a path/size-filtered nine-repository snapshot. It excludes other sites, larger rasters, private history and later publications. A detected duplicate is sufficient to stop; no incomplete scan can clear uniqueness.

01

Generate—not copy—a candidate

Use a preregistered method inside the assigned lane. Restore pinned inputs, build the new physical surface, test every feature for leakage. Never rename, jitter or re-encode a submitted mask to claim novelty.

Do not rerun the stopped H1 lane or place dots. A new run requires an assigned lane, complete registry, compatible incumbent and authenticated inputs; see the next-session criteria.

02

Require a positive automated decision

Check `run_card.json`: the verdict must be positive for selector consideration, the surface and final-dot checks must pass, and the candidate must beat a reconstructed incumbent on the same spatial holdout. Our current card says negative. Stop here.

Use whole withheld components, visible-only catalogue features, exact known-pixel masking, pooled DTI and spatial CI. A prebuilt prior file is not a valid OOF comparator.

03

Validate the actual on-disk file

A single-band GeoTIFF must match the submission template's CRS, shape and affine transform. This project's local diagnostic checks all values finite and in [0,1], zeros outside the footprint, no positive mass on mapped traces, and no hidden nodata mask. The official text asks for null/NaN outside the data bounds, and the sample mirror's irregular exterior is NaN. Portal handling has not been established; do not infer acceptance from either local encoding. The writer rejects bad predictions rather than silently clipping them.

The portal message “Predicted values must be in range [0, 1]” does not uniquely identify the cause. NaN, infinity, a finite nodata sentinel or a normalization bug must each be checked; this writer checks them automatically.

The ZIP contains exactly one TIFF. Current format receipt ↗ (format passed, scientific eligibility failed).

04

Use a separate quota-aware selector

Promotion to a weekly slot is separate from a model run. Retrieve the current rules and actual remaining quota from the authenticated submission page; the weekly cap is not verified in this session. Never invent it. No file is currently promoted.

05

Only with clearance: download and upload

Download the approved .tif or its single-TIF .zip, not an HTML/JSON report. Verify SHA-256 against the approved receipt. Sign in to the official submission page, check its quota and follow its upload controls for the authorized file and short note (at most 140 characters). The authenticated field labels were not verified here. Capture the organizer's actual receipt and reported result as ORGANIZER-CONFIRMED; never convert a local projection into a score.

This release's TIF is a research surface only and must not be used for this step.
